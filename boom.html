Nigel's software was used to drive the (boom) robot in the Fukushima Nuclear Reactor Decommissioning project. Nigel wrote the control software (HLC) layer for the VNS "boom style" robot that was use to enter the small vent (X2) at the back of the reactor container. The robots job was to survey the state of the reactor from the inside. It has since been commisioned to perform the actual removal of the dangerous material. The project commissioned on behalf of MHI (Mitsubishi Hitatchi Industries), who originally built the reactor an were leading the clean of the site. The HLC included simulation modes and a system to return the boom back to it's starting configuration (position), taking the sme route as was used duing use. This system makes an accidental collision while retracting the boom impossible, which is a significant gain for safety.
