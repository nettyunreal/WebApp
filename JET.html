The JET fussion reactor

The Joint European Torus (JET) was the European leg of the world wide drive for a working fusion power source. It is a tokamak (A ring composed of "D" shaped pieces) that use magnet fields to confine a mixture of duterium and tritium (DT) plasma.

Rhovr 2.0

The JET reactor was built by UK-AEA (Atomic Energy Authority). In turn, they created a division called RACE (Remote Applications for Challanging Environments). RACE in turn, created tools for remotely maintainence (and eventually decomissioning) of the JET reactor. The RHOVR project use a standard Game Engine (Unreal) to provide real-time visualisation of the state of the internal workings of the reactor. This allows the Remote Handling Operators (RHO) of the robots to plan and execute changes. My job was to reimagine the RHOVR system, to enable realtime manipulation of the 3D environment (which was too slow using the standard Unreal tools). When this was successfully acheived I was asked to extend to to support multiple users acting on the system at the same time. I completed this work, leaning on my experience of writing networking code for games(see games).
